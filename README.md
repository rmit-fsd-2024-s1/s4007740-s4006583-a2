# s4007740-s4006583-a1

SOIL - a food grocer website

gitHub URL link: https://github.com/rmit-fsd-2024-s1/s4007740-s4006583-a1.git

## Users are able to:

-create an account and login to make purchases
-view and manage their profile (edit name, email and password)(unique identity can signup with existing email)
-all specials are visible in both home page and products page
-products page allows filtering of product types
-add items to a shopping cart
-edit items in the shopping cart
-purchase items in shopping cart
-leave reviews for items
-edit and delete those reviews
-follow and unfollow other users

This project is built using Vite. To run on server, ensure you have Node.js and npm (or yarn) installed on your machine.

## Installations

To install Vite, run the following command:
npm install vite --save-dev

Run 'npm i' in both the DIRT and the server directories.

## Run project

To run the project, navigate to the DIRT directory and execute the following command:
npm run dev

Then navigate to the server directory and execute the following command:
npm run dev

Ensure you are in the correct directory before running this command.
